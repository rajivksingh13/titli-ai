Generative AI Technical Review – Incorrect vs Correct Definitions

1. Retrieval-Augmented Generation (RAG)

  • Incorrect Acronym: RAG was expanded as “brick table augmented generation.”
  • Incorrect Architecture Placement: RAG described as running on the front end to “process your prompt” rather than on the backend for retrieval and grounding.

2. Large Language Models (LLMs)

  • Incorrect Definition: LLM described as “a kind of data trained on a particular set of text data format.”
  • Incorrect Classification: Claimed that different LLMs are needed for image generation, video generation, etc.

3. Low-Rank Adaptation (LoRA)

  • Incorrect Definition: LoRA described as ranking/sorting multiple outputs (e.g., weather responses) and selecting the “best” output.

4. In-Context Learning (ICL)

  • Misdefinition: Explained as a tool for backend teams “to understand user requirements,” instead of an inference-time model behavior.

5. Image Generation Mechanism

  • Incorrect Explanation: Image generation described as “a vector embedding rendered on your front end.”

6. Fine-Tuning

  • Incorrect Analogy: Compared to customizing Python libraries like NumPy/Pandas instead of weight updates on a model.

7. Tokens

  • Incorrect Purpose: Defined as managing backend queries or tracking usage instead of being text units used for model processing.
