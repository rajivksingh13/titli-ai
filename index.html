Generative AI – Incorrect vs Correct Technical Concepts

This document highlights explanations that were technically incorrect and provides accurate definitions with simple, clear examples.

1. Retrieval-Augmented Generation (RAG)

Incorrect Explanation:

  • Misinterpreted as “brick table augmented generation.”
  • Described as a frontend mechanism used to process or improve prompts.

Correct Definition:

RAG is a backend architecture that retrieves relevant information from a vector database and augments a user prompt with real knowledge before sending it to an LLM. This improves factual accuracy and reduces hallucination.

Example:
Query: “What is Google’s 2023 leave policy?”
The system retrieves the policy text from internal documents → attaches it to the prompt → LLM produces a grounded answer.

2. Low-Rank Adaptation (LoRA)

Incorrect Explanation:

  • Defined as a mechanism that ranks or sorts multiple outputs (e.g., weather results).

Correct Definition:

LoRA is a parameter-efficient fine-tuning method that adds small low-rank matrices to a model, enabling low-cost customization without retraining the entire network.

Example:
Fine-tuning a base LLM using LoRA to become a domain-specific medical assistant by training only 1–2% additional parameters.

3. In-Context Learning (ICL)

Incorrect Explanation:

  • Explained as a backend-team feature used to better understand user needs.
  • Implied that models learn permanently from prompts.

Correct Definition:

ICL is the model’s ability to interpret examples provided directly inside the prompt, without updating any internal weights. This learning is temporary and lasts only for the duration of the conversation.

Example:
“Hola → Hello, Gracias → Thank you. Translate: Adiós →” → The model answers “Goodbye” by recognizing the pattern.

4. Image Generation Mechanism

Incorrect Explanation:

  • Described as “a vector embedding rendered on your front end.”

Correct Definition:

Modern image models (e.g., Stable Diffusion, DALL·E 3) use diffusion or GAN-based architectures. The prompt creates embeddings that guide the multi-step denoising process which results in a final coherent image.

Example:
Prompt: “A watercolor painting of an astronaut in a forest.” → Diffusion model generates the artwork through iterative refinement of noise.

5. Fine-Tuning

Incorrect Explanation:

  • Compared to customizing Python libraries such as NumPy or Pandas.

Correct Definition:

Fine-tuning updates a pre-trained model’s internal weights using domain-specific data. This requires GPU training, datasets, and gradient-based optimization.

Example:
Fine-tuning a general LLM on 30,000 HR documents to build an accurate HR-policy chatbot.

6. Tokens

Incorrect Explanation:

  • Defined as mechanisms for tracking usage or managing queries.

Correct Definition:

Tokens are the smallest units of text (words, subwords, punctuation) processed by an LLM. They determine cost, latency, and how much context the model can handle.

Example:
The sentence “AI is powerful.” may be split into tokens like “AI”, “ is”, “ powerful”, “.” depending on the tokenizer used.
